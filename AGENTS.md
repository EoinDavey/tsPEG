# Project Information: tsPEG

## Project Overview

tsPEG is a PEG (Parsing Expression Grammar) parser generator for TypeScript. It takes a grammar file (`.peg`) as input and generates a TypeScript module containing a parser for that grammar.

The generated parser is type-safe, creating an Abstract Syntax Tree (AST) with corresponding TypeScript interfaces and classes. It supports advanced features like left-recursion, memoization (for performance), and detailed error reporting.

## Core Technologies

*   **Language:** TypeScript
*   **Platform:** Node.js
*   **Testing:** Jest
*   **Package Manager:** npm

## Project Structure

*   `src/`: The main source code for the tsPEG generator.
    *   `cli.ts`: The command-line interface for the tool.
    *   `gen.ts`: The core parser generation logic.
    *   `template.ts`: The template for the generated parser file.
    *   `metagrammar.peg`: The grammar that defines the tsPEG grammar syntax itself.
    *   `parser.gen.ts`: The parser for the metagrammar, generated from `metagrammar.peg`. **Do not edit this file directly.**
    *   `test/`: Unit tests and test grammars.
*   `demos/`: Example grammars and usage, including a JSON parser and a calculator.
*   `package.json`: Project dependencies, scripts, and metadata.
*   `gen-tests.sh`: A shell script to generate parsers for the test grammars in `src/test/`.
*   `jest.config.mjs`: Jest configuration.
*   `tsconfig.json`: TypeScript compiler configuration.

## Development Workflow

The following npm scripts are defined in `package.json`:

*   `npm run build`: Compiles the TypeScript source code. This includes a step to regenerate the `src/parser.gen.ts` parser.
*   `npm run test`: Runs the full test suite. This first generates parsers for all test grammars using `./gen-tests.sh`, then runs Jest tests, and finally runs the linter.
*   `npm run lint`: Runs ESLint on the source code.
*   `npm run clean`: Removes the `tsbuild/` directory.

**To regenerate the metagrammar parser:**

The parser for the tsPEG grammar itself (`src/parser.gen.ts`) is generated from `src/metagrammar.peg`. The `npm run build` command handles this, but it can also be done manually with `npm run gen`.

## Testing

The testing strategy involves several components:

1.  **Test Grammars:** The `src/test/` directory contains numerous subdirectories, each with a `grammar.peg` file and a `test.test.ts` file.
2.  **Parser Generation:** The `gen-tests.sh` script iterates through the test directories and uses the `tspeg` CLI to generate a `parser.ts` file for each grammar. Some tests use a `flags.txt` file to pass specific options to the `tspeg` CLI.
3.  **Jest Tests:** The `*.test.ts` files contain Jest tests that import the generated `parser.ts` and assert its correctness against various inputs.

The full test suite can be run with `npm test`.
